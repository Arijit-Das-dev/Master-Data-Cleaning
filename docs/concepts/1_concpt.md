### Why we need data cleaning ?
- In real world, data comes from multiple sources containing some inconsistancy. That data can contain missing values, duplicates and other type of some critical errors. That erros or mistakes makes that data inconsistant and misunderstood for analysing it. It becomes impossible 
to get insights from it. That's why we need to clean that data as much as possible so that it can provide usuful insights for better business decisions.
