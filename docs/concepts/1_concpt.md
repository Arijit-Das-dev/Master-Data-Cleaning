# Concepts 

### Why we need data cleaning ?
- In real world, data comes from multiple sources containing some inconsistancy. That data can contain missing values, duplicates and other type of some critical errors. That erros or mistakes makes that data inconsistant and misunderstood for analysing it. It becomes impossible 
to get insights. That's why we need to clean that data as much as possible so that it can provide usuful insights for better business decisions.

### Data source :
- Data comes from multiple sources. such as,
1. Databases
2. Websites
3. Cloud storages
4. From APIs
5. Surveys

### Where we store that data ?
- We store that data in data werehouses, cloud storages, databases before cleaning it.
